# Repository guidance

- Treat `src/` as the source of truth. `dist/` is generated by `npm run build`.
- Keep PureImage's implementation dependency-free at runtime beyond its existing pure JavaScript dependencies.
- For focused unit tests, use `npm run vitest -- <test-file>`; use `npm run type-check` for TypeScript checks.
- The canvas conformance runner is `npm run wpt -- [filter]`. WPT tests run against `src/`; update `test/wpt/baseline.json` only when intentionally changing the accepted pass set.
- Keep rendering changes covered by pixel-level regression tests where practical.
